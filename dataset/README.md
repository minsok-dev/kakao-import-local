원본 `input/raw/<방id>/photos` 는 **그대로 둔다.** 여기에는 **복사본만** 넣는다.

```text
dataset/
  poster/        ← 댄스인포에 올릴 장 (사이트에 올린 포스터 복사 가능)
  non_poster/    ← 올리면 안 되는 장
```

## 장수

| 단계 | poster | non_poster |
|------|-------:|-----------:|
| C1 착수 시험 | 80+ | 80+ |
| 기본 | 300+ | 300+ |

수량보다 **종류**. 식탁만 100장이면 안 된다.

## poster 에 넣을 것

강습·파티 포스터, 글자 적은 홍보, 단체사진형 홍보, 콜라주, 인스타 캡처형 포스터, 가로·흑백·손글씨, 날짜만 바꾼 재개강.

## non_poster 에 넣을 것

식탁·셀카·선풍기만이 아니라 **hard negative**: 카톡/인스타 캡처, 메뉴판, 영수증, 제품 광고, 밈, 유튜브 썸네일, 댄스 아닌 일정표, 공연 장면만, 글자 많은 상품 소개.

같은 파일 재압축 20장은 넣지 않는다. 같은 유형이면 여러 장이 낫다.

## 파일명

자유. 분류기는 폴더(긍정/부정)와 내용 해시로 본다.  
방 원본 파일명(`KakaoTalk_…`)을 유지한 채 복사해도 된다.

이미지는 git에 올리지 않는다 (`.gitignore`).
