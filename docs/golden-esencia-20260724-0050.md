## 매칭 방식 정리

| 방식 | 가능? | 비고 |
|------|-------|------|
| txt 본문에 `KakaoTalk_….png` 문자열 | ❌ | 실측 0건 |
| 파일명 `KakaoTalk_YYYYMMDD_HHMMSSmmm` → datetime 파싱 후 메시지 시각과 대조 | ✅ | **본 예시로 확인** |
| 같은 분(minute)에 `사진` N개 ↔ 파일 N개 순서 | ✅ | 00:50:30 / 00:50:34 ↔ 사진 2줄 |

## Matcher 규칙 초안 (이 예시 기준)

1. `KakaoTalk_` 패턴만 시각 추출  
2. 메시지 절대시각 = 직전 일자 헤더 날짜 + `[오전/오후 h:mm]`  
3. 파일 시각과 **동일 분(또는 ±수 초~분 윈도우)** 의 `] 사진` / `] 사진 N장` 후보  
4. 같은 분에 사진 메시지 K개·파일 K개면 **시간순 정렬 후 1:1**  
5. 후보가 여러 방·여러 화자면 **ambiguous → review**  
6. 비 `KakaoTalk_` 파일명은 이 규칙 제외  

## 잔여 리스크

- 나중에 몰아서 저장하면 파일명 시각이 전송 시각과 어긋날 수 있음 → 윈도우·ambiguous  
- 같은 시각대 다른 방의 `사진`과 충돌 가능
