# 개인정보 · 보존 정책 (Phase 0/1 필수)

<!-- [변경사유]: Phase 0/1에 개인정보·보존을 포함 — 리뷰 피드백 반영 -->

## 1. 수집 경로 표현

개인 카카오톡 대화와 첨부 이미지를 자동 수집하는 **공식 범용 API가 없으므로**,  
PC 다운로드 파일과 대화 내보내기를 사용한다.

## 2. 원본 보존

| 규칙 | 내용 |
|------|------|
| 금지 | 원본 export·이미지 **수정·삭제·이동·덮어쓰기** |
| 허용 | 읽기 전용 스캔, SQLite에 메타·fingerprint·결정만 저장 |
| CLI | delete/원본 변경 명령 **제공하지 않음** |

## 3. 로그

- **전체 메시지 본문**을 애플리케이션 로그에 남기지 않음  
- 로그: 건수, fingerprint 앞 N자, room_key, 오류 코드 중심  
- `LOG_LEVEL`로 제어

## 4. SQLite

| 항목 | 정책 |
|------|------|
| 기본 위치 | `./data/kakao_local.db` (프로젝트 상대, gitignore) |
| 접근 | 해당 PC 사용자 권한; 공유 폴더·클라우드 동기화 경로 비권장 |
| 백업 | 운영자가 수동; 기본 보존 기간은 운영 합의 (문서화 후 설정) |
| 발신자 | 기본은 **저장 가능하되** 마스킹 옵션; 서버 전송 시 최소 필요만 |
| 본문 | 로컬 DB에 matched/merged에 필요한 범위만; 서버에는 **인접 메시지**만 |

## 5. 마스킹

- 전화번호, 개인 링크, 실명(샘플 fixture) 마스킹  
- 서버 전송 payload에 로컬 **절대경로 금지** (상대경로·sha256만)

## 6. 서버 전송 범위

- 필요한 **인접(matched/merged) 메시지**만  
- 채팅방 전체 dump 업로드 금지  
- Import 전용 토큰 사용 시에도 Cookie 저장 금지

## 7. 상태

정책 초안 ✅ — 보존 기간 일수·발신자 기본 on/off는 운영 합의 후 숫자로 고정.
